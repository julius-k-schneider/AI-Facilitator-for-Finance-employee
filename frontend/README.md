## Frontend Setup

The frontend is built with React and Vite.

Before running the project, make sure that Node.js is installed on your computer.  
You can check this by running:

- node -v
- npm -v

To start the frontend locally, follow these steps:

- cd frontend
- npm install
- npm run dev

After running npm run dev, the terminal will show local development URL, for example:
http://localhost:5173/

Open this URL in your browser to view the frontend.
